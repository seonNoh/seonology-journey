# README structure contract

The three README files must use the same heading hierarchy and equivalent diagram positions.

1. Project title and language switcher
2. Architecture
3. Components
4. Requirements
5. Quick start
6. Verification
7. Delivery
8. Operations
9. Repository policy
10. License

English uses `README.md`, Korean uses `README.ko.md`, and Japanese uses `README.ja.md`. Each language references its corresponding Relief SVG variant under `assets/diagrams`.
